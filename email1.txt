How to Install and Test the Package:

To test the package, you can set up a clean Python environment and follow these steps:

1. Install the package directly from PyPI:
   pip install matpower-python

2. Test the Command-Line Interface (CLI):
   The package registers 23 direct terminal commands. Try running these to run simulations and automatically export reports to Excel or Word:
   * AC Power Flow on Case 14, output to Excel:
     acpf case14 1e-4 excel
     (Generates acpf_case14.xlsx)
   * Holomorphic Embedding on Case 9, output to Word:
     hepf case9 docx
     (Generates hepf_case9.docx)
   * Export Solver Help Menu to a Word Document:
     hepf --help docx
     (Generates hepf_help.docx)

3. Test the Python Scripting Mode:
   You can import the module directly in your custom Python scripts to load test cases, access standard MATPOWER indexing constants, and run simulations programmatically:
   
   import power_python as pp

   case = pp.PowerCase()
   case.load_from_json("outputs/json/case9.json")

   # Run Holomorphic Embedding
   case, success = pp.run_hepf(case)
   if success:
       print(f"Bus 1 Voltage Magnitude: {case.bus[0, pp.VM]} p.u.")
